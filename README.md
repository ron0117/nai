# 无忧辅助工具

半透明、可置顶的 Electron 悬浮层，用来按团队轮转提醒谁该点技能。主持端用 WebSocket 长连接把轴进度同步给队员。

## 规则

每人间隔 = `技能CD / 团队人数`。

默认 `120 / 24 = 5s`，到点后提示持续 `4s`。人数中途改了，间隔会立刻按新人数重算。

## 启动

```bash
npm install
npm start
```

## 用法

1. 在控制台填 CD、持续时间和人数。
2. 点自己的座位，悬浮层只会在轮到你时加强提醒并响一声。
3. 点 **开始**。需要组队同步时，一人点 **开始主持**，其他人填写六位房间密码后加入。
4. 进游戏前勾选 **鼠标穿透**，避免挡住技能点击。

覆盖游戏请用无边框窗口模式。独占全屏下系统不允许普通窗口浮在游戏上。

## 快捷键

- `Ctrl+Shift+S` 开始 / 暂停
- `Ctrl+Shift+L` 鼠标穿透
- `Ctrl+Shift+H` 显示 / 隐藏悬浮层
